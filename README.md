# 🛒 Supermart Grocery Retail Analytics

An end-to-end **Retail Analytics** project using the Supermart Grocery Sales dataset.

## 📌 Project Overview

This project analyzes grocery sales data to identify sales and profit patterns and generate useful business insights.

### 🔍 Analysis Includes

* Exploratory Data Analysis (EDA)
* Sales & Profit Analysis
* Outlier Analysis
* Association Rule Mining
* Classification
* Data Warehousing
* Data Visualization

## 🛠️ Tools & Technologies

**Python • Pandas • NumPy • Matplotlib • Seaborn • Scikit-learn • Jupyter Notebook**

## 📂 Project Structure

```text
01_Notebook          → Main analysis notebook
02_Documentation     → Project documentation
03_Dataset           → Original dataset
04_EDA_Results       → EDA & outlier results
05_Association_Rules → Frequent itemsets & rules
06_Classification    → Classification results
07_Data_Warehouse    → Data warehouse files
08_Charts            → Analysis visualizations
99_Checkpoints       → Notebook checkpoints
```

## ▶️ How to Run

Open the notebook from `01_Notebook` in **Jupyter Notebook or VS Code** and run the cells sequentially.
